# Maharashtra Election Connect

Build a production-quality, fully navigable working prototype for the State Election Commission of Maharashtra, using the attached SEC_website_core_Analysis_FULL_UPDATED.xlsx as the authoritative functional/UX requirements source. Prioritize the specified Priority 1 core platform, then Candidate & Voter flows, then RO workflows. Establish reusable information architecture, design system, structured mock/CMS data layer and metadata model, global search, dependent Local Body Type → District → Local Body → Ward filtering, and WCAG 2.1 AA-oriented accessibility before building pages. Use clearly labeled realistic demo data only; do not invent official facts, dates, legal provisions, officers, results or contacts. Make all interactions functional, including inclusive date filtering, inline form validation, external-link behavior, search/filtering, role-based journeys, and mobile responsive navigation. Build the homepage and the connected service sections described in the brief, not disconnected static pages. Use English/Marathi-ready translation architecture. Treat official content as CMS/API replaceable.
